# Будильник

Android alarm clock with repeat schedules, custom ringtone selection, vibration,
and a 10-minute snooze.

## Download

Download the signed APK from `Будильник.apk` and install it on an Android phone.
Android may ask you to allow installation from the browser or file manager used
to open the APK.

## Website

The static download page is `index.html`; it expects `Будильник.apk`,
`styles.css`, and `script.js` in the same folder.

## Android source

The Android Studio project is included in `android-source.zip`. The signing
keystore and passwords are intentionally not included.
